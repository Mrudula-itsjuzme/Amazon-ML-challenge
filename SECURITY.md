# Security Policy

## Reporting a vulnerability
Please **do not** disclose exploitable vulnerabilities, access tokens, private data, or credentials in a public issue.

Use GitHub's **Report a vulnerability** / private vulnerability reporting feature in this repository's Security tab, if enabled. If it is not available, contact the repository maintainer privately using a contact channel they explicitly publish on their GitHub profile. Never post the vulnerability or secrets publicly.

A maintainer will triage reports as availability permits. No response-time SLA or security support contract is promised.

## Scope and limitations
This repository is provided as-is. Unless explicitly documented, experimental code and models have not been independently security-audited and should not be assumed suitable for production or safety-critical use.

If you discover an exposed credential, revoke or rotate it with the provider immediately. Deleting a file from the latest commit does not erase prior commit history or copies already downloaded.
